# Inventaris aset

35 ilustrasi orisinal disediakan berpasangan sebagai assets/source-vector/NAMA.svg dan assets/runtime/NAMA.png. Sprite runtime ditanam di dalam CAPX.

| Kelompok | Nama sumber |
|---|---|
| Karakter | CatAiming, CatCharging, CatDefeat, CatHappy, CatHit, CatIdle, CatThrowing, CatVictory, DogAiming, DogCharging, DogDefeat, DogHappy, DogHit, DogIdle, DogThrowing, DogVictory |
| Arena, antarmuka dan efek | Again, Aim, Back, Bone, Card, Energy, Fence, Footer, Garden, Help, Home, HudPlate, Life, Logo, Meter, Panel, Play, Puff, Start |

Whoosh menandai peluncuran, Pop menandai karakter terkena, Thud menandai lemparan berakhir, Cheer menandai ronde selesai. assets/audio menyimpan master WAV dan runtime Ogg Vorbis. Ikon dan logo loading bawaan berasal dari proyek beta Construct 2.
